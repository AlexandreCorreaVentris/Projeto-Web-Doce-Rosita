# Rosita Doces Artesanais

## 1. Apresentação do projeto

O projeto Rosita Doces Artesanais consiste no desenvolvimento de um site para apresentação de produtos de confeitaria.

O site apresenta diferentes categorias de produtos, incluindo bolos, doces, salgados e geladinhos gourmet.

A proposta é criar uma experiência visual agradável, organizada e interativa para os visitantes.

O desenvolvimento faz parte das atividades práticas da disciplina de Web Design.

O projeto utiliza HTML, CSS e JavaScript.

## 2. Objetivo geral

Desenvolver um site com páginas interativas para apresentação dos produtos da Rosita Doces Artesanais.

## 3. Objetivos específicos

- Organizar o conteúdo utilizando HTML.
- Desenvolver uma identidade visual utilizando CSS.
- Implementar funcionalidades interativas com JavaScript.
- Criar um carrossel de apresentação dos produtos.
- Desenvolver menus de navegação.
- Criar uma página específica para geladinhos gourmet.
- Permitir a seleção de sabores e quantidades.
- Simular valores de pedidos.
- Utilizar Git para controle de versões.
- Publicar o projeto no GitHub.

## 4. Tecnologias utilizadas

### HTML5

Utilizado para estruturar as páginas do site.

Organiza cabeçalhos, menus, imagens, botões, seções e rodapés.

### CSS3

Utilizado para estilização e apresentação visual.

Define cores, fontes, posicionamentos, tamanhos e efeitos.

### JavaScript

Utilizado para implementar funcionalidades interativas.

Permite manipular elementos HTML e responder às ações dos usuários.

### Git

Utilizado para registrar as alterações realizadas durante o desenvolvimento.

### GitHub

Utilizado para armazenar e disponibilizar o código-fonte do projeto.

### GitHub Pages

Utilizado para publicar o site na internet.

### Visual Studio Code

Editor utilizado durante o desenvolvimento do projeto.

## 5. Estrutura do projeto

O projeto está organizado em páginas e arquivos específicos.

O arquivo `index.html` funciona como entrada do site.

O arquivo `inicio.html` apresenta a página inicial.

O arquivo `style.css` contém os estilos da página inicial.

O arquivo `script.js` contém as funcionalidades JavaScript da página inicial.

A pasta `geladinho` contém a página dedicada aos geladinhos gourmet.

O arquivo `geladinho.html` apresenta os sabores e o sistema de pedidos.

O arquivo `geladinho.css` contém a estilização dessa página.

O arquivo `geladinho.js` contém as funcionalidades interativas dos geladinhos.

A pasta `imagens` armazena os recursos visuais utilizados no site.

## 6. Funcionalidades JavaScript

### 6.1. Carrossel automático

O carrossel apresenta diferentes categorias de produtos.

As imagens são alternadas automaticamente.

O intervalo programado entre as trocas é de cinco segundos.

### 6.2. Navegação manual do carrossel

O usuário pode avançar para o próximo slide.

Também pode retornar ao slide anterior.

Os indicadores permitem selecionar diretamente uma apresentação.

### 6.3. Menus suspensos

Os menus apresentam opções adicionais de navegação.

A abertura ocorre por meio de cliques.

Os menus podem ser fechados ao clicar fora deles.

Também podem ser fechados pressionando a tecla Esc.

### 6.4. Miniaturas interativas

As miniaturas apresentam imagens relacionadas aos slides.

O JavaScript associa as miniaturas às imagens do carrossel.

Também permite navegar para seções específicas da página.

### 6.5. Cabeçalho dinâmico

O cabeçalho responde à rolagem da página.

Uma classe CSS é ativada após determinada distância de rolagem.

Isso permite modificar a apresentação do cabeçalho.

### 6.6. Emblema animado

A página de geladinhos apresenta o emblema da Rosita.

O emblema altera seu tamanho e sua posição durante a rolagem.

A animação é controlada por JavaScript.

### 6.7. Prévia dos sabores

O usuário pode selecionar diferentes sabores de geladinhos.

O sistema apresenta o nome e o preço do produto.

Também existe uma área destinada à fotografia do sabor.

### 6.8. Janela de seleção

Ao clicar em um sabor, uma janela interativa é apresentada.

A janela permite escolher a quantidade desejada.

O usuário pode aumentar ou diminuir essa quantidade.

### 6.9. Cálculo do subtotal

O JavaScript multiplica o preço unitário pela quantidade selecionada.

O resultado é apresentado em reais.

A formatação monetária utiliza o padrão brasileiro.

### 6.10. Carrinho de pedidos

O usuário pode adicionar diferentes sabores ao pedido.

O sistema armazena os itens selecionados durante a utilização da página.

As quantidades podem ser modificadas.

Os produtos podem ser removidos individualmente.

O valor total é atualizado automaticamente.

### 6.11. Limpeza do pedido

O usuário pode limpar todos os itens do carrinho.

O sistema solicita uma confirmação antes da limpeza.

### 6.12. Cópia do resumo

O JavaScript prepara um resumo dos produtos selecionados.

O resumo apresenta quantidades e valores.

O usuário pode copiar essas informações para a área de transferência.

## 7. Organização dos arquivos JavaScript

As funcionalidades da página inicial estão no arquivo `script.js`.

As funcionalidades da página de geladinhos estão no arquivo `geladinho.js`.

A utilização de arquivos externos facilita a manutenção do projeto.

Também permite separar a estrutura HTML da programação JavaScript.
